画日系插画的人，十个里有八个在透视和布料褶皱上翻过车。你画一个角色坐在窗台上，腿的比例怎么调都别扭；画一件飘起来的裙子，褶皱的走向全靠猜，画完自己都不知道对不对。这些问题靠2D硬画，画十张错十张。3D辅助的意义就在这里：它不是帮你画得更好看，是帮你画得更准。

但3D辅助日系插画有一个常见的翻车方式：你导进一个模型，摆好Pose，渲染出来，然后照着渲染图描线、上色。结果画面带着一股“模型味”——边缘太硬、布料像塑料、脸没有表情、光影死板。问题不在3D本身，在你把它当成了描图工具，而不是参考工具。正确的流程是：建模打底→渲染参考→2D细化，三个阶段各干各的事，不能混着来。

第一阶段：建模打底，交付的是“能看清结构的姿态”。

这个阶段的核心不是建一个精细的模型，是把透视和体块关系定死。日系插画最吃透视的地方是手、脚、头部转向、以及布料和身体的贴合关系。这些东西用2D画，靠感觉猜，画十张错八张；用3D摆，五分钟就能看出哪里不对。

具体做法：用现成的带骨骼模型（DAZ、VRoid、或者任何能摆Pose的FBX），摆出你想要的姿态。相机焦距调到50到85mm之间，避免广角畸变。机位定好之后，不要急着渲染成品图，先输出三样东西：带线框的透视图（用来检查结构和透视）、白模带光影的图（用来检查体积和明暗关系）、法线图（后期在PS里做局部光影调整用）。这个阶段的交付标准是：你看着这张白模图，能清楚说出角色每个部位在空间里的位置关系，手和脚没有透视硬伤，布料和身体的贴合逻辑成立。

第二阶段：渲染参考，交付的是“能读的材质和光影”。

这个阶段最容易走偏。很多人一进材质和灯光，就开始追求“好看的渲染图”，皮肤要次表面散射、布料要物理正确、灯光要电影级。结果渲染出来的图太“实”了，你照着画，画出来像3D渲染，不像日系插画。

日系插画的渲染参考，核心是提供材质分区和光影逻辑，而不是提供最终效果。你需要从渲染图里读出的信息是：哪块是皮肤、哪块是布料、哪块是金属、哪块是头发；主光从哪来、明暗交界线在哪、投影落在哪、反光在哪。所以渲染设置要往“清晰、干净、对比明确”的方向调，而不是往“真实、细腻、氛围感”的方向调。EEVEE实时渲染就够用，材质用基础色加粗糙度就够，灯光用两盏灯把体积和投影打清楚就够。交付标准：一张能看清材质分区和光影层次的参考图，加一张AO图用来加深暗部，加一张材质遮罩用来在PS里选区。

第三阶段：2D细化，交付的是“日系插画的语言”。

这是整个流程里最关键、也最容易被3D带偏的阶段。你渲染出来的图不是成品，是底稿。日系插画有一套自己的视觉语言：线稿有粗细变化、阴影是色块而不是渐变、高光是形状而不是光斑、布料褶皱有明确的节奏和方向。这些东西3D渲染给不了你，必须靠2D重画。

具体操作：在渲染底图上新建图层，先描线。线稿不要照着渲染图的边缘描，要用日系插画的线条逻辑重新组织——外轮廓线粗、内部结构线细、转折处加重、布料褶皱用弧线而不是折线。然后上色，不要用渲染图的颜色直接吸，要在日系插画的配色逻辑下重新选色：肤色偏粉、阴影偏紫、高光偏冷、整体饱和度控制住。最后处理脸和手，这两个地方3D模型的表情和结构几乎不可用，必须完全重画。交付标准：一张线稿有日系语言、色块分明、脸和手重新绘制过的成图。

三个阶段走完，你手里应该有一张透视准确、光影有依据、但视觉语言完全是日系插画的成图。它看起来不像3D渲染，但它的结构和透视经得起推敲。3D在这个流程里的价值，不是替你画，是替你算。 算透视、算体块、算光影落点。算完之后，画还是你自己画。

最后说一个自检方法：把成图和渲染参考图并排看。如果成图只是渲染图的“描边加平涂版”，说明你被3D带偏了；如果成图在渲染图的结构基础上，长出了日系插画自己的线条节奏和色彩逻辑，说明你跑通了。今天就去摆一个你最画不准的姿势，别打开绘画软件。
